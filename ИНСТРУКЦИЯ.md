# Тетрадь заметок: установка

## 1. База для синхронизации (Supabase, бесплатно)
1. Зарегистрируйтесь на https://supabase.com и нажмите **New project** (любое имя, придумайте пароль базы, регион — Frankfurt).
2. Откройте **SQL Editor → New query**, вставьте всё содержимое файла `supabase.sql` и нажмите **Run**.
3. Необязательно, но удобно: **Authentication → Sign In / Providers → Email** и выключите **Confirm email**. Тогда аккаунт в приложении создаётся сразу, без письма.
4. Откройте **Project Settings → API** и скопируйте **Project URL** и ключ **anon public**.
5. Вставьте их в файл `config.js` между кавычками и сохраните.

## 2. Размещение (GitHub Pages, бесплатно)
1. Зарегистрируйтесь на https://github.com и нажмите **New repository**: имя `notes`, тип **Public**, создать.
2. На странице репозитория нажмите **uploading an existing file** и перетащите все файлы и папку `icons` из архива. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**, в **Branch** выберите `main` и `/ (root)`, нажмите **Save**.
4. Через минуту появится адрес вида `https://ваш-ник.github.io/notes/`.

## 3. Установка на устройства
- **ПК (Chrome или Edge):** откройте адрес и нажмите значок установки в адресной строке (монитор со стрелкой) → «Установить».
- **Android (Chrome):** меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
- **iPhone (Safari):** «Поделиться» → «На экран Домой».

Внутри приложения нажмите строку синхронизации внизу слева (на телефоне — точку справа от папок), создайте аккаунт и войдите под ним же на всех устройствах.

## Если что-то пошло не так
- Приложение работает и без интернета, правки отправятся при подключении.
- Там же, в окне синхронизации, есть «Скачать копию» — резервный файл всех заметок.
- Обновили файлы на GitHub, а изменений не видно? Увеличьте номер `VERSION` в `sw.js` и перезапустите приложение.
